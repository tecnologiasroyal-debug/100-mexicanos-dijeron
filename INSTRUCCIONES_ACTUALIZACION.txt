ACTUALIZAR GITHUB + PYTHONANYWHERE
1) Descomprime este ZIP.
2) En GitHub abre el repositorio 100-mexicanos-dijeron.
3) Add file > Upload files.
4) Sube TODO EL CONTENIDO de la carpeta 100_Mexicanos_Dijeron_COMPLETO_V4, reemplazando los archivos existentes.
5) Commit changes.
6) En PythonAnywhere abre Consoles > Bash.
7) Ejecuta:

   cd ~/100-mexicanos-dijeron
   git pull

8) Ve a Web y pulsa Reload rivaspruebas.pythonanywhere.com.
9) Recarga con Ctrl+F5 (Windows) o Cmd+Shift+R (Mac) para evitar caché.
